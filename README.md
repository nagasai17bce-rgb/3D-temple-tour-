# Yatra — AI Virtual Pilgrimage

AI-powered temple discovery and virtual pilgrimage prototype.

## Flow

User problem → AI temple recommendation → personalized journey → virtual temple experience → contextual AI guide → next stop.

## GitHub Pages

This repository includes a GitHub Actions deployment workflow at `.github/workflows/deploy-pages.yml`.

To publish it:
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **GitHub Actions**.
3. Pushes to `main` will deploy automatically.
